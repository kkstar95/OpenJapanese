# OpenJapanese (Open Source Japanese Language Learning Tools)

I was annoyed you don't have too many 100% FREE options when it comes to starting Japanese so i decide to build one myself.

Uses VC++6 so should be compatible with every Windows Platform. These are vibe coded but i did test them myself originally they were suppose to be fun games i play in my free time anyways. When it comes to language AI Agents are quite accurate but if i see any mistake or someone reports it i will fix the code.

> [!NOTE]
Hiragana Support\
Katakana Support\
Kanji Support N1,N2,N3,N4,N5 JLPT Levels (Onyomi and Kunyomi)\
Uses Native Dark Mode\
Supports Windows Sounds For Correct/Incorrect Answers\
Punishment System (Every -1 Reduces Score)\
Hotkey or Click Options\
Accuracy Meter and Swap Options\
Up to 50 Rounds Per Test
>
